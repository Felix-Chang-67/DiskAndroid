## 本版新增 1：盘上的文件
放入数据盘（DVD、BD、CD-ROM、自己刻的盘），盘片卡片里会出现"盘上的文件"：
- 第一行是卷标和文件系统，例如「ライブ…」· UDF 1.02 + ISO 9660 + Joliet。
- "内容"一行是盘片类型：DVD-Video、BD-Video（BDMV）、BDAV（蓝光录像机录的）、AVCHD、DVD-VR、Video CD；其他算"数据盘"。BD 上有 AACS 文件夹会注明"AACS 加密"。
- 下面是文件列表：点文件夹进入；上方的路径可以点，回到上一级或根目录。文件显示大小和修改时间，隐藏文件颜色浅一些。
- 文件名支持日文：UDF 和 Joliet 本来就是 Unicode；只有 ISO 9660 文件名的盘，按 UTF-8 → Shift-JIS → GBK 的顺序猜编码。
- 音乐 CD 带数据区段时（加强版 CD），为了不和播放抢光驱，要点"查看数据区段里的文件"才会读。

### 复制文件
- 复制到和"读成 ISO"相同的保存位置。可以复制单个文件（文件右边的"复制"）、当前文件夹、或整张盘的文件；文件夹结构会原样建好。
- 通知栏显示进度，可以取消。读不出的扇区重试 3 次，仍然不行就补零，结果里会列出是哪些文件。
- 有版权保护的盘不提供复制：CSS 加密的 DVD、CPRM（数字电视录像）、带 AACS 的 BD。Video CD 的视频在特殊扇区里，暂时也不行。

## 本版新增 2：读成 ISO 的改进
- **文件名用正确的卷标**：优先用 UDF / Joliet 卷标，ISO 9660 卷标按 UTF-8 / Shift-JIS 解码。上次 `_________LIVE_AT_LIQUIDROOM_EXTR` 前面的 9 个下划线，其实是 3 个 UTF-8 日文字。
- **可重写盘只读文件系统部分**：DVD+RW、DVD-RW、DVD-RAM、BD-RE 不管刻了多少，光驱报的都是整张盘的容量（4.7 GB / 25 GB）。现在先读文件系统，只读到它的结尾，得到的镜像和当初刻进去的 ISO 一样，也快很多。需要整张盘时选"整张盘"。
- 报告（.iso.log）里多了文件系统详情，包括卷标的原始字节。读盘中途光驱有复位的话，报告和结果里也会列出来。

## 测试步骤
1. **上次那张 DVD+RW**：
   - 看"盘上的文件"里的卷标和文件列表，日文是否正常。
   - 在"读成 ISO"里应该显示"只读文件系统部分"和实际大小。读一次，看文件名、用时，以及中途还会不会卡。
2. **其他数据盘**（有什么试什么）：
   - 自己刻的 CD-R / DVD±R（最好有日文文件名）；
   - 演唱会 DVD / BD 的特典数据盘；
   - 用 Windows"类似于 USB 闪存驱动器"方式刻的盘；
   - 自制 DVD-Video / BD。

   每张盘看卷标、盘片类型、目录能不能逐级打开。
3. **商业 DVD / BD**：确认"内容"里认出了 DVD-Video / BDMV，并注明不能复制的原因（CSS / AACS）。
4. **加强版 CD**（如有）：点"查看数据区段里的文件"。
5. **复制**：
   - 复制一个文件，在文件管理器里打开看看；
   - 再复制一个文件夹，中途取消一次。
6. 测完点"导出日志（zip）"发给我。
