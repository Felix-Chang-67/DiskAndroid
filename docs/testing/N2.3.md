# 测试节点 N2.3：播放 DVD（含光盘菜单）

- 版本：`0.9.0-N2.3`（versionCode 10），直接覆盖安装（签名与之前相同）。
- APK 比上一版大了约 5 MB：里面多了自写的视频播放器（libdvdnav + FFmpeg）。

## 上次（N2.2）的结果
- 两张商业 DVD（CSS 加密，地区 2）、那张 DVD+RW、一张 BD 的标题和主片都认对了。
- DVD+RW 的卷标正确显示为「ヒトリエ LIVE at LIQUIDROOM Extra Video」。
- 解码器清单：这台平板**没有 MPEG-2 解码器**（DVD 的视频格式），也没有 DTS / TrueHD。所以本版的播放器全部用软件解码，不依赖平板自带的解码器。
- 第二张商业 DVD 读标题时多读了 2 次加密扇区（光驱拒绝，没有影响结果），已改成只读到文件末尾。

## 本版新增：DVD 播放（按你的要求支持光盘菜单等全部功能）

### 怎么开始播放
- 放入**没有加密**的 DVD 视频盘：先出现“2 秒后播放”，可以点“取消”或“立即播放”。
  - 在“视频内容”里可以关掉自动播放，或者选择从哪里开始：“光盘菜单”（和 DVD 机一样，从片头 / 菜单开始）或“直接播放主片”。
- 也可以在“视频内容”里手动点：
  - **▶ 从光盘菜单开始**
  - **▶ 直接播放主片**
  - 标题列表里每个标题后面的“播放”
- 播放界面全屏横屏。播放中屏幕不会熄灭。

### 播放界面怎么操作
- **在菜单里**（光盘自己的菜单）：
  - 直接点菜单上的按钮。
  - 按住拖动可以移动高亮。
  - 右上角“操作”打开控制栏；控制栏里的“方向键”在屏幕上显示 ▲▼◀▶ 和“确定”，用于点不准的菜单。
- **播放中**：点画面显示 / 隐藏控制栏，4 秒不动会自动隐藏。
  - **上面一排**：
    - “← 关闭”
    - 当前位置（标题 / 章节）
    - “光盘菜单”“标题菜单”，在菜单里还有“返回上级”
    - **音轨**、**字幕**、**角度**：显示语言和格式，点开可以切换
    - “方向键”
  - **下面一排**：
    - 进度条（可以拖动）
    - 上一章、−10 秒、播放 / 暂停、+30 秒、下一章
    - 章节列表、标题列表
    - 最右边的小字是技术信息：分辨率、音频格式、已读盘多少 MB、补零的扇区数、丢帧数
- **键盘 / 遥控器**：
  - 菜单里：方向键移动高亮，确定键选择。
  - 播放中：
    - 左 / 右键：快退 / 快进
    - 空格或播放键：暂停 / 继续
    - 媒体键：上一章 / 下一章
- **返回键**或“← 关闭”：停止播放，回到主界面。

### 自动行为
- **离开播放界面会暂停**（回桌面、锁屏），回来后点“播放”继续。
- 拔耳机、来电、别的 App 开始放声音时也会暂停。
- **弹出盘片或拔掉光驱：立即停止**，自动回到主界面。
- **字幕**：盘上有中文字幕、光盘又没有自己打开字幕时，自动打开中文字幕。
- **音轨**：光盘没指定音轨时，优先选日语。
- **读不出的扇区**（划伤）：先重读；还是读不出就跳过那一小段继续放，并记进日志。

### 加密盘和地区码
- **CSS 加密的商业 DVD**：会提示“**该盘有版权保护，需要启用解密组件**”，不会尝试播放。解密是阶段 3 的工作。
- **BD**：播放在下一个节点（N2.4）加入。
- **地区码**：“视频内容”里会显示盘片和光驱的地区。
  - 两者不匹配时会明确提示。
  - App 只读取地区码，不会修改光驱的地区设置。

## 测试步骤
1. **上次那张 DVD+RW**（ヒトリエ … Extra Video；英语 AC-3，带中文字幕）：
   1. 放入后等“2 秒后播放”自动开始（或者点“▶ 从光盘菜单开始”）。如果这张盘有菜单，试一下点按钮、拖动、屏幕方向键。
   2. 看画面：比例对不对（16:9，左右或上下有黑边是正常的），有没有花屏、锯齿、拖影。
   3. 听声音：有没有声音，有没有断续，和口型 / 动作对不对得上。
   4. 字幕：中文字幕是不是自动出来了；在“字幕”里关掉、再打开。
   5. 拖动进度条，点上一章 / 下一章，−10 秒 / +30 秒，暂停 / 继续，在“标题”里换到另一个标题。
   6. 按返回键退出，再点“▶ 直接播放主片”。
   7. 播放中按光驱的弹出键：播放应立刻停止，回到主界面。放回盘，应再次出现“2 秒后播放”。
2. **商业 DVD**（CSS 加密）：放入后应提示“该盘有版权保护，需要启用解密组件”，不会开始播放。
3. **其他没有加密的 DVD 视频盘**（自己刻的 DVD-R / DVD+R、带菜单的更好）：如果有，也照第 1 步试一遍。
4. 测完点“导出日志（zip）”发给我。
