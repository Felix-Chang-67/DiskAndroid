# 测试节点 N3：蓝光播放 + 加密 DVD / 蓝光（阶段 3）

- 版本：`0.10.0-N3`（versionCode 12），直接覆盖安装（签名与之前相同）。
- 这次除了 APK，还有两个**单独的文件**（不在 APK 里，按你的要求做成可选的外部组件）：
  - `libdvdcss.so`：DVD 解密组件（CSS）
  - `libaacs.so`：蓝光解密组件（AACS）
- 蓝光还需要 **KEYDB.cfg**（AACS 密钥库，文本文件）。这个要你自己准备，我这边不提供。

## 上次（N2.3）的结果
- 没有加密的 DVD 能正常播放，但有卡顿。
- 日志里读盘是正常的（单次读取中位数 4 ms，没有读错，缓冲有好几秒），所以问题在画面节奏和声音输出。本版做了这些改进（原来的 N2.3b，合并进本版）：
  - 告诉系统视频的帧率，让 144 Hz 的屏幕切换到能整除 29.97 帧的刷新率。
  - 画面带上"应该显示的时刻"交给系统，由系统对准屏幕刷新。
  - 提高音频线程、画面线程的优先级；声音缓冲开到最大。
  - **播放时每 10 秒在日志里写一条统计**（帧率、丢帧、晚到的帧、两帧之间最长的间隔、解码耗时、声音欠载次数、读盘耗时）。如果还卡，日志能直接看出卡在哪。

## 本版新增

### 1. 蓝光播放（全功能）
- 和 DVD 一样，可以**从光盘菜单开始**，也可以**直接播放主片**，或在"视频内容"的列表里播放任意一个播放列表。
- **光盘菜单**：First Play（片头）、顶层菜单、播放中的**弹出菜单**、菜单按钮（点按、拖动选择、屏幕方向键、遥控器）。
- 播放界面上面一排（蓝光）：
  - "顶层菜单"：回到光盘的主菜单。
  - "弹出菜单"：光盘提供弹出菜单时才出现，再按一次关闭。
  - 音轨、字幕、角度：显示语言和格式，可以切换。
- 下面一排：进度条、上一章 / 下一章、−10 秒 / +30 秒、章节列表、标题列表（直接播放时是播放列表）。最右边的技术信息显示实际在用的解码器（例如"H.264 1920×1080 TrueHD"）。
- 格式：视频 H.264、HEVC、VC-1、MPEG-2；音频 AC-3、E-AC-3、DTS / DTS-HD、TrueHD、LPCM；字幕（PG）。全部软件解码。
- **BD-J 菜单**（用 Java 写的菜单）在 Android 上做不了。遇到这种盘会**自动直接播放主片**，顶栏会写"BD-J 菜单不支持，直接播放主片"。
- 放入蓝光后同样有"2 秒后播放"（可取消；从光盘菜单还是直接主片，和 DVD 用同一个设置）。
- 蓝光的播放器地区默认是 A（日本）。

### 2. 加密盘（阶段 3）
- 组件不随 App 提供，由你导入；只用于边读边播。**不提供解密后导出；"读成 ISO"对加密盘仍然是原始密文。**
- App **不会修改光驱的地区码**（设置地区码的命令在最底层就被拦截了）。
- **DVD（CSS）**：导入 `libdvdcss.so` 后，商业 DVD 播放时由它向光驱认证，然后边读边解密。菜单、音轨、字幕和没加密的 DVD 一样。
- **蓝光（AACS）**：导入 `libaacs.so` 和 `KEYDB.cfg` 后，打开盘时按这个顺序找密钥：
  1. KEYDB.cfg 里这张盘的密钥（VUK）——最可靠，不用和光驱认证。
  2. 以前算出来缓存的密钥。
  3. 用 KEYDB.cfg 里的处理密钥算出媒体密钥，再用主机证书**向光驱认证**，读出卷标识。较新的光驱固件会拒绝已经公开（被吊销）的主机证书，这时会提示"该光驱不支持此盘的认证"。
- **不支持**：4K Ultra HD 蓝光（AACS 2.0）、BD+（另一种保护）。遇到会直接提示。
- KEYDB.cfg 很大（几十 MB）时，每次打开蓝光要多等几秒（libaacs 要把整个文件读一遍）。

## 怎么导入组件
1. 把我发的 `libdvdcss.so`、`libaacs.so` 保存到平板上（例如"下载"文件夹）。KEYDB.cfg 也放到平板上。
2. 打开 App，主界面往下滑，光驱卡片下面有 **"解密组件"** 卡片（不接光驱也能看到）。
3. 三行各点一次 **"导入…"**，分别选：
   - "DVD 解密组件" → `libdvdcss.so`
   - "蓝光解密组件" → `libaacs.so`
   - "AACS 密钥库" → `KEYDB.cfg`
4. 每行会显示"已导入"、文件大小和 SHA-256 的前几位。
   - 导入时会检查：是不是 64 位 ARM 的库、能不能加载、是不是给 DiskAndroid 编的版本；KEYDB.cfg 是不是密钥库格式。
   - 不对的话会说原因，不会保存。
5. "删除"会把组件连同它缓存的密钥一起删掉。

## 可能看到的提示
| 提示 | 意思 |
|---|---|
| 该盘有版权保护，需要启用解密组件 | 没导入对应的组件（蓝光还会说缺的是组件还是 KEYDB.cfg） |
| 光驱拒绝认证：盘片地区和光驱地区不符 | DVD 的地区码和光驱的不一样（App 不会去改光驱） |
| CSS 认证没有成功… | DVD 认证失败，原因在日志里 |
| KEYDB.cfg 里没有这张盘的密钥（VUK），也没有能处理这张盘（MKB 版本 N）的处理密钥 | KEYDB.cfg 里没有这张盘；N 越大盘越新 |
| KEYDB.cfg 里没有这张盘的密钥（VUK）；要向光驱读卷标识，但 KEYDB.cfg 里没有可用的主机证书 | 同上，而且没有主机证书可用 |
| 该光驱不支持此盘的认证：… | 光驱拒绝了 AACS 认证（后面附光驱返回的错误码，完整记录在日志里） |
| 不支持 AACS 2.0（4K UHD 蓝光） / 这张盘除了 AACS 还有 BD+ 保护 | 这两种不支持 |
| AACS 解密不对：读到的视频还是加密的 | 打开成功但解出来不对，多半是 KEYDB.cfg 里这张盘的密钥不对 |

## 测试步骤
1. **还没导入组件时**：
   1. 放商业 DVD：应提示"该盘有版权保护，需要启用解密组件"。
   2. 放商业蓝光：同样提示，并说明缺组件和 KEYDB.cfg。
2. **导入 DVD 组件**（`libdvdcss.so`），然后放商业 DVD：
   1. 点"▶ 从光盘菜单开始"（或等自动播放）：片头、菜单，点按钮进正片。
   2. 正片里试：拖动进度、章节、音轨 / 字幕切换、"光盘菜单"。
   3. 注意画面是否流畅、有没有花屏。
3. **导入蓝光组件和 KEYDB.cfg**，然后放商业蓝光（新旧不同年份的盘各一张最好）：
   1. 点"▶ 从光盘菜单开始"：片头、顶层菜单，点按钮进正片。
   2. 正片里试"弹出菜单"（如果光盘有）、"顶层菜单"、章节、音轨 / 字幕切换、拖动。
   3. 退出后再点"▶ 直接播放主片"。
   4. 打不开的话，记下提示的原文。
4. **上次卡顿的 DVD+RW**：放 2–3 分钟，看还卡不卡。
5. 测完点"导出日志（zip）"发给我。

## 需要你告诉我的
- 每张盘：能不能播、菜单能不能用、画面 / 声音 / 字幕有没有问题、卡不卡、打不开时的提示原文。
- 日志 zip。相关的标签：
  - `VIDEO`：播放器（含每 10 秒的播放统计）。
  - `VIDEO/CSS`、`VIDEO/AACS`：解密组件自己的记录（密钥、证书一律打码成 `<...>`，只保留盘 ID）。
  - `VIDEO/BD`、`VIDEO/BLURAY`：蓝光导航。
  - `SCSI`：每条认证命令（命令、结果、光驱返回的**原始 sense**；密钥类数据不写进日志）。
  - `DECRYPT`：组件导入；`GUARD`：被只读守卫拦下的命令（正常情况下应该没有）。
