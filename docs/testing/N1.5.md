# 测试节点 N1.5：音乐 CD 播放（日文 CD-TEXT）

- 版本：`0.4.0-N1.5`（versionCode 4），直接覆盖安装（签名与之前相同）。
- 按你"日本盘优先"的要求，音乐 CD 播放（原计划的 N1.5）提前到读成 ISO（N1.4）之前。

## 本版新增
- **播放音乐 CD**：盘片就绪后出现"音乐 CD"卡片，有专辑名、艺人、曲目列表，点曲目就开始播放。
  - 上一首 / 下一首 / 暂停 / 拖动进度条；跨轨连续播放（无缝）；播到最后一首结尾自动停止。
  - 息屏、锁屏后继续播放；通知栏和锁屏上有控制按钮；蓝牙耳机按键可用。
  - 拔耳机自动暂停；来电或其他 App 播放时暂停，导航播报时压低音量。
  - 播放时把光驱降到约 4 倍速（更安静、更省电），停止后恢复。
- **CD-TEXT 日文曲名**：日文块优先（Shift-JIS，包括 ①、Ⅱ、～ 这类 Windows 扩展字符）；有英文 / 罗马字块时作为副标题显示。没有 CD-TEXT 的盘显示 Track 1、Track 2……（这是正常的）。
- **读错处理**：读不出来的地方会先重试，再逐个扇区重试，仍然不行就静音这一小段并在界面上计数，播放不会卡死。
- **早期 CD 的预加重**：1980 年代的部分 CD 录音时做了预加重，这类音轨会标"预加重"，播放时自动做去加重（可以在"播放设置"里关掉对比）。

## 本版同时修正了 N1.3 发现的问题
- 你的光驱的 USB 桥接芯片在读取长度为奇数时会传错后半段数据（N1.3 那张 10 轨 CD 的"完整 TOC"缺了第 9、10 轨，还多出一个假的"区段 0"）。现在所有读取长度都对齐到 4 字节，并且逐条校验完整 TOC。
- 音乐 CD 的容量改为显示总时长。
- 光驱型号：从桥接芯片的附加信息里解出机芯是 **HL-DT-ST BD-RE BU40N**（固件 BN14），显示在"光驱详细信息"里。

## 安装
和之前一样：在对话里下载 APK → 点开安装（覆盖旧版本，不需要先卸载）。

**HyperOS 设置（建议做一次，否则息屏后可能被系统停掉）：**
1. 设置 → 应用设置 → 应用管理 → DiskAndroid → 省电策略 → **无限制**。
2. 在最近任务里把 DiskAndroid **锁定**（下拉卡片或长按），避免一划就被强制停止。
3. 如果系统问是否允许通知，选允许（不允许也能播放，只是通知栏没有控制按钮）。

## 测试步骤
1. 接好光驱（带供电的扩展坞），放入一张**日本的音乐 CD**，等显示"就绪"。
2. 看"音乐 CD"卡片：
   - 专辑名、艺人、每首曲名是否和歌词本 / 盒子背面一致；日文有没有乱码、缺字。
   - 曲目数和每首时长是否正确。
3. 点第 1 首播放，听 1–2 分钟：
   - 有没有杂音、爆音、断续。**如果全是沙沙的噪音**，在"播放设置"里把字节序改成"大端"再听，并告诉我。
   - 从点击到出声大概多久。
4. 试各个按钮：暂停 / 继续、下一首、上一首（一首开头 3 秒内按是上一首，3 秒后按是回到本首开头）、拖动进度条。
5. 按电源键息屏 3–5 分钟，看是否一直在播；在锁屏和通知栏上用控制按钮切歌、暂停。
6. 如果有耳机：播放中拔掉耳机（或断开蓝牙），应该自动暂停。
7. **播放中按光驱上的弹出键**：应该马上停止，界面显示盘片已取出，App 不卡死。放回去后再播一次。
8. **播放中拔掉光驱的 USB 线**：应该马上停止，不卡死、不闪退。插回去后能重新连接并播放。
9. 可选：
   - 有划痕的 CD：听卡顿情况，看界面上"已静音 N 个读不出的扇区"；
   - 1980 年代的老 CD（可能带预加重）、2002–2004 年的 CCCD（防复制 CD）、加强版 CD（有电脑数据的那种）。
10. 测完点"导出日志（zip）"发给我。

## 需要你告诉我的
- 曲名显示是否正确（有问题的话拍一下歌词本对应的那一页最好）。
- 听感：杂音 / 爆音 / 断续（大概在第几首、几分几秒）。
- 息屏播放、锁屏控制、弹盘、拔线各项是否正常。
- 导出的日志 zip。

## 关于日志
- 播放时每条 READ CD 命令都会记一行精简日志（CDB、长度、结果、耗时），只写进日志文件，App 内的日志面板不显示这些流水，免得把其他日志挤掉；出错的命令照常完整记录（含 sense 原始 hex）。
- 日志里 `PLAYER`、`CDDA` 标签是播放器的记录，`DISC` 里有 CD-TEXT 的完整原始数据。
