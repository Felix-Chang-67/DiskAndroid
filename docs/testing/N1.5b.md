# 测试节点 N1.5b：在线识别曲名、封面与歌词

- 版本：`0.5.0-N1.5b`（versionCode 5），直接覆盖安装（签名与之前相同）。
- 新增联网权限：只用于查询曲目信息、封面和歌词，可以在"播放设置"里关掉。

## 你上次那张 CD
日志里的光盘目录在 MusicBrainz 上精确匹配到：**ヒトリエ《DEEPER》**（2016-02-24，日本发行，通常盤）。网易云音乐上同一张专辑的 10 首时长全部吻合，有中文译名（例如 シャッタードール → 摄影人偶），也有带中文翻译的同步歌词。

## 本版新增：在线识别（参考 MusicTag 的做法）
1. 放入音乐 CD 后，按光盘目录（每首的起点和长度，相当于一张盘的"指纹"）在 **MusicBrainz** 查。这是开放的音乐数据库，日本盘收录不少，曲名是日文原名，还有发行日期、版本（通常盤 / 初回限定盤）和封面。
2. 查不到时，读盘上的 **JAN 条码**再查一次（不是每张盘都写了条码）。
3. 认出专辑后，到**网易云音乐**找时长吻合的同一张专辑，补上中文译名、封面和**歌词**（日文原文 + 中文翻译，跟着播放进度走）。
4. 还是认不出来：点"手动识别"，输入专辑名或艺人搜索。结果按与这张 CD 的时长吻合程度排序，选一个即可。
5. 识别结果、歌词和封面都保存在平板上，同一张盘下次放进来直接显示，不再联网。

联网只发送光盘目录、条码、搜索词和歌曲编号，不发送任何个人信息。

## 本版同时修了上次的读盘卡顿
上次日志里，播放时每隔一阵就会卡住约 6 秒，同时有 0.3 秒左右没声音。原因判断如下：Android 内核给一次 56 KB 的 USB 传输分配内存时偶尔失败，我的程序误以为是光驱的问题，触发了复位。本版改为：
- 每次传输最多 16 KB；
- 内存不足就原地重试；
- 遇到传输错误后重新读那一块数据，不再静音；
- 播放缓冲加大到约 10 秒，即使偶尔发生一次复位也不会断音。

## 测试步骤
1. 安装后接好光驱，放入上次那张《DEEPER》：
   - 几秒后应显示专辑名、日文曲名（下一行灰色小字是中文译名）、发行日期和封面；
   - 卡片里写"曲目信息：MusicBrainz + 网易云音乐"。
2. 播放第 2 首，看歌词是否跟着走（当前行高亮，下面是中文翻译）。点"全部歌词"可以看整首。
3. 从头到尾连续播放整张专辑（大约 41 分钟，可以息屏），看还有没有卡顿或短暂无声。
4. 再放几张别的日本 CD，特别是：
   - 冷门一点的盘：MusicBrainz 可能没有，这时看手动搜索好不好用；
   - 初回限定盘、带 bonus track 的盘：看版本对不对。
5. 识别错了：点"结果不对？"，从"其他候选"里选，或者手动搜索。
6. 锁屏和通知栏上应显示正确的曲名和封面。
7. 测完点"导出日志（zip）"发给我。
