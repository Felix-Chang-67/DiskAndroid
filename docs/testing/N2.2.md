- 版本：`0.8.0-N2.2`（versionCode 9），直接覆盖安装（签名与之前相同）。

## 本版新增：视频内容
放入 DVD 或 BD 后，盘片卡片里多了“视频内容”，在“盘上的文件”上面：
- 列出所有标题（BD 是播放列表）：时长、章节数、角度、大小、视频格式、每条音轨（语言、格式、声道）和字幕语言。
- **自动挑出主片**：
  - DVD 挑最长的标题。几个一样长时，优先选单元顺序正常的（有些防拷贝的盘会放打乱顺序的假标题）。
  - BD 和 libbluray（VLC 等播放器用的库）的规则一样：先去掉重复的和反复循环同一段的播放列表，再比章节、分辨率、无损音轨、时长。
- 挑得不对，可以在“其他标题”里点“选这个”；不到 10 秒的标题（片头警告、菜单背景之类）默认折叠。
- 有 CSS / AACS 加密的商业盘照样能看标题列表，因为加密只针对视频数据，播放要等阶段 3。
- **解码器**一行列出这台平板能否直接解码选中标题的视频和音频。DVD 常见的是 MPEG-2 视频 + AC-3（杜比数字）音频；设备没有的格式，播放时要用软件解码，这是为下一步播放做准备。

## 测试步骤
1. **演唱会 DVD / BD**（加密的也可以）：每张盘看“视频内容”。
   - 主片是不是正片（时长、章节数对得上）？不对的话点正确的那个“选这个”，并告诉我是哪张盘、正确的是哪个标题。
   - 音轨（例如日语 LPCM / AC-3）和字幕语言对不对。
2. **上次那张 DVD+RW**：卷标应显示「ヒトリエ LIVE at LIQUIDROOM Extra Video」。可以再读一次 ISO，看文件名。
3. **自制 DVD-Video / AVCHD**（如有）：同样看标题列表。
4. 看一眼“解码器”那一行：哪些是 ✓，哪些是 ✗。
5. 测完点“导出日志（zip）”发给我。
