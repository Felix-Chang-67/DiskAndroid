# 测试节点 N1.3：盘片信息（容量、TOC、轨道、盘片结构）

- 版本：`0.3.0-N1.3`（versionCode 3），直接覆盖安装。
- 盘片就绪后，App 自动读取：READ CAPACITY（容量）、READ DISC INFORMATION（盘片状态 / 区段数）、READ TOC（格式 0 轨道表；CD 另读格式 1 区段信息、格式 2 完整 TOC）、READ TRACK INFORMATION（每条轨道）、READ DISC STRUCTURE（DVD 物理格式与版权信息、BD 盘片信息）、GET PERFORMANCE（读取速度）。
- 依然只读：不读取盘片内容本身（扇区数据要到 N1.4 / N1.5），不读取任何密钥类结构（DVD 盘钥、CPRM、AACS 格式在守卫层被拦截）。

## 本版同时修正了 N1.2 真机测试里发现的问题
- 一次开/关托盘会记两条事件 → 现在只记一条。
- "已锁定 是"是误读：那一位表示"支持锁定"，不是当前状态；当前锁定状态改从 2Ah 页读取。
- MODE SENSE 改为"先读头、再按确切长度读"，避开 N1.2 日志里那次 STALL（当时已正确恢复，但能避开就避开）。
- AACS 特性按 libaacs 的位定义显示：总线加密、可读光驱证书。
- 读取完整 96 字节 INQUIRY，看看桥接芯片的厂商自定义区里有没有真实机芯信息。

## 测试步骤
1. 安装后接上光驱，依次放入你手头的盘（有几种测几种）：
   - **音乐 CD**（最好有带 CD-TEXT 的，或者"加强版 CD"——音轨 + 电脑数据）
   - **CD-ROM 或自刻 CD-R**（如果有追加写过多次的 CD-R 更好）
   - **DVD**：DVD 视频碟（正版或自制都行）和/或数据 DVD±R
   - **BD**：BD-ROM 或 BD-R
2. 每张盘等到"就绪"，看卡片里的"盘片信息"：
   - 类型、容量是否合理（CD 约 700 MB / 80 分钟，DVD 4.7 / 8.5 GB，BD 25 / 50 GB）
   - CD：轨道数、每轨时长是否与盘面印的一致
   - DVD 视频碟：是否显示"CSS 加密"，盘片地区是几区（盘面通常印有地区码）
   - 如果出现橙色提示"盘片地区与光驱地区不符"，说明以后播放这张加密盘会受限（见下）
3. 全部测完后，点"导出日志（zip）"把 zip 发给我（日志里有每张盘读到的完整信息和原始 hex）。

## 关于 DVD 地区码（N1.2 读到的结果）
你的光驱是 **RPC-II、当前地区 2**（日本 / 欧洲 / 中东等），用户还能修改 4 次。
RPC-II 光驱在固件里强制地区：**加密（CSS）DVD 的地区如果不包含 2，光驱会拒绝读取加密扇区**——这与 App 无关，App 也绝不会自动修改地区码。
- 全区（0 区）或包含 2 区的 DVD：不受影响。
- 中国大陆是 6 区，港台是 3 区，美国是 1 区：这些加密盘在当前设置下会受限。
这次测试会显示你每张 DVD 的地区，便于提前判断。是否修改光驱地区由你决定：每改一次消耗一次机会，剩余的 4 次用完后地区会被永久锁定。需要时我再说明在本 App 之外怎么做（本 App 不提供这个功能）。
